What this project is

A power grid is not operated from its wires — it is operated from an estimate of its wires. This project asks how much damage an attacker can do by corrupting that estimate, and — unlike every prior study — asks it at every hour of a full year rather than at a single operating snapshot.

This dashboard accompanies the mid-term review. It presents the approach, the standard dataset, the grid models and the verified before-attack baseline. Attack results are not shown — they will be presented at the end-term review.

The cyber-physical power system

A modern power system is two coupled networks: the physical grid of generators, lines and transformers, and a digital control layer above it.

  • Field devices — RTUs, IEDs, PMUs and smart meters — measure voltages, currents and power flows continuously.
  • Those readings travel over communication protocols (IEC 60870-5-104, DNP3, IEC 61850) to the SCADA / EMS at the control centre.
  • Software there estimates the system state and computes the control actions, which are sent back to the field.
  • Most of these operational-technology protocols were designed for reliability, not security: many carry no authentication or message integrity by default.
A manipulated measurement can be as damaging as a manipulated breaker — because the operator acts on data.

  • It attacks the data, not the equipment — no physical access to a substation is required.
  • It leaves the bad-data alarm silent, so the defence already in place never fires.
  • It corrupts the OPF input, so the operator is made to cause the damage — and the result is measurable in MW and $/hour.

What is state estimation?

Meters are noisy and redundant, so the control centre does not read the state — it estimates it. Weighted Least Squares finds the state that minimises the weighted squared residual between actual and predicted measurements:

J(x)  =  Σi ( zi − hi(x) )2 / σi2
  • Solved by Gauss–Newton iteration using the Jacobian H = ∂h/∂x.
  • Output: every bus voltage magnitude and angle — n = 2nb − 1 states, the slack angle being the reference.
  • The surplus of measurements over states is the redundancy that makes bad-data detection possible at all.

What is bad data detection?

At the converged estimate the residual J follows a chi-square distribution with ν = m − n degrees of freedom. If J exceeds the 95% threshold, the operator declares bad data and rejects the estimate.

An attack is stealthy when it leaves J essentially unchanged — so the alarm never fires, at any confidence level.

Standard test data — IEEE RTS-GMLC

The Reliability Test System maintained by the Grid Modernization Lab Consortium — the field's benchmark for time-series power-system studies.

  • Why a standard dataset: it makes the study reproducible and comparable with other published work; a synthetic profile would not be.
  • What is used: hourly regional load for one full year — 8,784 hours, with the leap day dropped to give exactly 8,760.
  • How it is applied: the system-total load shape is normalised to per-unit of annual peak, giving an hourly multiplier that scales the benchmark IEEE bus loads.
  • Citation: C. Barrows et al., “The IEEE Reliability Test System: A Proposed 2019 Update,” IEEE Trans. Power Systems, vol. 35, no. 1, 2020.

Why the nonlinear AC model?

DC model (common in the literature)Nonlinear AC model (used here)
Voltage magnitudes assumed flat at 1.0 puVoltage magnitudes are state variables
Reactive power ignoredReactive power fully represented
Line losses assumed zeroLosses computed — the metric we need
Linear: z = HxNonlinear: z = h(x) + e
  • A DC study cannot report transmission loss, because in that model the loss is identically zero by assumption.
  • Real state estimation is AC. An attack designed on a DC model often fails in AC — the neglected terms appear in the residual.
  • Voltage limits and generator reactive limits, which decide whether an attack is physically feasible, exist only in the AC model.

Choice of optimisation algorithm

AlgorithmNatureNote
Genetic AlgorithmEvolutionaryCrossover/mutation; many parameters
Simulated AnnealingSingle-solutionSlow on rugged, constrained spaces
Tabu SearchMemory-basedNeeds a tailored neighbourhood
Particle Swarm (PSO)Swarm3 parameters; mixed variables
GTO / KOA / ARORecent nature-inspiredUsed by the base work for comparison
  • The base work compared PSO, GTO, KOA and ARO at one snapshot and all converged to similar attacks — the optimiser is not the deciding factor.
  • PSO handles mixed discrete and continuous variables, needs no derivative, and has only three parameters.
  • It must run 8,760 times per system, so cost per search matters.
v  ←  w·v  +  c1·r1·(pbest − x)  +  c2·r2·(gbest − x)      x  ←  x + v

Each particle is one complete attack: x = [angle bus, voltage bus, Δθ, ΔV]. w = 0.9, c1 = c2 = 2.05 — the tuning the base work validated.

How one hour is computed

for t = 1 : 8760                    % every hour of the year
    mpc     = scale_load(base_case, mult(t));
    ropf    = runopf(mpc);          % honest dispatch
    x       = state_of(ropf);       % the true state
    z       = h(x) + noise;         % synthetic meter data
    [xh, J] = wls_gauss_newton(z);  % state estimation
    best    = pso_search(@(c) fitness(c, xh, z));
    save(sprintf('hour_%05d.mat', t), best);
end

Evaluating one candidate attack

function f = evaluate_attack_fitness(c, x, z)
    a       = h(x + c) - h(x);      % exact nonlinear attack
    [xa, J] = wls_gauss_newton(z + a);
    if J > chi2_limit,   f = +Inf; return; end   % detected
    if V_violation(xa),  f = +Inf; return; end   % infeasible
    ratt    = runopf(network_as_it_appears(xa));
    rtrue   = runpf(true_network, ratt.Pg);
    f = -(rtrue.loss - baseline_loss);
end

Returning +∞ removes an invalid candidate from the swarm. The negative sign converts the minimiser into a maximiser of damage.
